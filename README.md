# Ungauged Basin Discharge — a literature review

A bilingual (English / Tiếng Việt) review of methods for estimating river
discharge in basins that have no usable gauge record.

The review sorts the literature by **what information reaches the ungauged
basin**, which gives seven method families:

1. Parameter regionalisation
2. Streamflow regionalisation
3. Donor-free (a priori and global) routes
4. Remote sensing of the river
5. Surrogate discharge
6. Deep learning (LSTM)
7. Hybrid and differentiable models

Alongside the families it covers the terrain and channel-geometry layer that the
satellite methods depend on, cross-cutting issues (large-sample data,
benchmarking, uncertainty), a side-by-side comparison, the open gaps, and a
ten-paper reading path.

It cites **123 references**. Each one carries its 2025 JCR quartile and impact
factor, and is marked with the evidence tier it was checked at: full text or
abstract. Every quantitative claim is taken from the source paper itself.

Every section has an anchor you can link to directly, for example `#surrogate`,
`#geom` or `#refs`. The **Tiếng Việt** button on each card switches that card to
Vietnamese.

Author: Chi Vuong Tai, HydroUNSW, UNSW Sydney.
